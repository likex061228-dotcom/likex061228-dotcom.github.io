A PROJECT IS A PLACE TO START

有一个想法，
就从一次实验开始。

先选一个能理解的系统，改变输入，观察反馈。把当前状态保存下来，再比较下一次尝试。这里从我的项目出发，也为新的想法留下位置。

01 / PROJECT LIBRARY

从一个完整项目开始。

CONTROL / VISION

车载平衡滚球

在同一个系统中观察球、升降机构、底盘与赛道。保留全部任务，比较控制与视觉延迟。

打开滚球实验 ↗
ROBOTICS / DECISION

循声避障小车

遥控、扫描避障、双路声音判断。移动障碍和声源，看清每一步决策，也观察算法的局限。

打开小车实验 ↗
MOTION / INTERACTION

重力 LED 点阵

亲手倾斜板子，让光点滚动与堆积。把观看视角和板子输入分开，探索姿态与显示的关系。

打开点阵实验 ↗

04 / METHODS & ADVANCED MECHANICS

从项目，走向新的问题。

想整理分析与验证过程，可以探索数学建模工作流。想从标准机械模型开始，可以进入原生MuJoCo工作区，编辑质量、关节和执行器。当前项目库采用明确标注的行为模型；高级机械工作区独立使用原生物理求解器。

新想法可以先从已有项目复制、修改并保存；复杂机构可由助手准备MJCF后导入高级工作区。当前没有“任意文字自动建模”服务。
